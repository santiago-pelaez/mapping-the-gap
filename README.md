# Mapping the Gap: Correcting FCC Broadband Maps

This is a web-based decision game for my DTC 475 Unit 1 final project. The game asks players to review broadband coverage case files from tribal land and decide whether each official provider claim should be challenged, verified as covered, or flagged as needing more evidence.

The project connects broadband mapping to tribal infrastructure access. It shows how inaccurate provider-submitted coverage claims can make underserved communities appear connected, which can affect funding eligibility and policy decisions.

## How to Play

1. Start the challenge desk.
2. Read each case file.
3. Choose one decision:
   - Submit Challenge
   - Verify As Covered
   - Need More Evidence
4. Try to correctly challenge enough false coverage claims to unlock funding eligibility.

## Project Files

- `index.html` contains the page structure, reflection, and bibliography.
- `styles.css` contains the visual design and responsive layout.
- `game.mjs` contains the game logic and canvas rendering.
- `data.mjs` contains the map regions and case data.

## Research Focus

The game is based on research about FCC broadband mapping, the Broadband Data Collection process, tribal broadband funding barriers, and network sovereignty. Its main argument is that inaccurate broadband maps can make tribal land and infrastructure needs less visible to policymakers, forcing Tribes to prove gaps in access before funding can reach them.
