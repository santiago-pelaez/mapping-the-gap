How This Connects

  • Provider-reported data: The official map begins from broadband availability claims submitted by providers.
  • Challenge process: The player must decide when evidence is strong enough to dispute an availability claim.
  • Funding consequences: False coverage claims can make underserved tribal areas look ineligible or lower priority.
  • Epistemic injustice: The dashed boundary keeps tribal sovereignty visible on a map that can otherwise erase it.

Project Reflection

I chose to make a web game because I think the interactive aspect forces players to experience the frustrating realities Indigenous communities face in getting reliable broadband and government funding for it. My game has an irregular, earth-toned map that makes the user verify whether network connectivity is actually there or not.

The main mechanics represent the real-world problem of misreporting areas with no or limited connectivity as having broadband available. From the older Form 477 system to the newer BDC reporting, there are still inaccurate provider-submitted map claims. The game makes the player engage in a process where they dispute false coverage claims.

Failing to correct the map results in funding denial, which mirrors the real struggle of bad map data causing lack of funding and implementation barriers for Tribes trying to build and sustain networks. The misreported tiles in my game represent the information asymmetry and epistemic injustice Marisa Elena Duarte talks about in her book.

Accurate mapping is critical since flawed federal maps can render tribal land invisible to policymakers. The core idea of the game is to teach the player that this network exclusion is an ongoing systemic barrier that forces tribes to fight just to prove they need infrastructure.
