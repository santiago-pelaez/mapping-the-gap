Reflection Prompt

This project uses a case-file decision game because the broadband map problem is not only about whether a region is colored as covered. Each case asks the player to compare a provider claim with evidence from people who live inside the boundary: failed service orders, terrain-blocked wireless signals, missing address records, confirmed installations, or affordability concerns. That format makes the research concrete. FCC broadband data depends on reported availability and a formal challenge process, so the game rewards decisions that match what the process can actually accept as evidence.

The map and funding meter show why those decisions matter for tribal broadband access. When false coverage claims remain unchallenged, underserved areas can appear served and funding stays blocked or at risk. When strong evidence corrects the map, the same places become visible to the system. The dashed tribal boundary is part of that argument: it keeps sovereignty and local geography in view while showing how official data can blur or erase the difference between nearby infrastructure and real home service.
